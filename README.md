# Rounded Desktop Selection

A Windhawk mod that gives the Windows desktop drag-selection rectangle a
translucent fill and rounded corners. Color, opacity, radius and border width
are configurable. Windows keeps its native rectangular selection behavior.

**Version 0.1.2 · experimental MVP · Windows 11 x64**

[Português](docs/README.pt-BR.md) · [Configuration](docs/configuration.md) ·
[Development](docs/development.md) · [Changelog](CHANGELOG.md)

![Rendered preview of the default appearance](docs/preview.png)

The preview above is generated by the rendering tests, not a desktop capture.
Defaults: `#E81123`, 20% fill opacity, 80% border opacity, 8 DIP corner radius,
and a 1 DIP border.

## Compatibility

- Validated with Windhawk 1.7.3 on Windows 11 x64, OS build 26300 and
  `comctl32.dll` version 6.0.26100.9278.
- Desktop selection only. File Explorer's DirectUI file view is outside this MVP.
- ARM64, Windows 10, other Windows builds and mixed-DPI monitor configurations
  have not been validated.
- The mod relies on private Windows symbols and a recognized instruction
  pattern. An unrecognized layout prevents initialization; a failed geometry
  read uses native drawing.
- Avoid combining it with other mods that replace desktop marquee painting.
- If selection fails with Lively Wallpaper running, first test native selection
  with this mod disabled. During initial validation, closing Lively restored
  native selection; this is an observed interaction, not a universal diagnosis.

## Install using Windhawk

1. Install [Windhawk](https://windhawk.net/).
2. Choose **Create a New Mod** to open its development editor.
3. Replace the entire `mod.wh.cpp` content with
   [rounded-desktop-selection.wh.cpp](rounded-desktop-selection.wh.cpp).
4. Compile and enable the mod using the Windhawk sidebar.
5. Adjust its Settings, then drag on an empty area of the desktop.

The mod is a local mod; this repository does not imply inclusion in Windhawk's
official mod collection. No changes to Windows theme files are required.

## Build and install from this repository

Requires Windows x64, PowerShell 5.1 or 7, and the compiler bundled with Windhawk.
From the repository directory:

```powershell
.\scripts\check-project.ps1
.\build.ps1
.\build.ps1 -Test
```

`build.ps1` discovers the compiler and engine paths from `windhawk.ini` and reads
the mod ID and version from the C++ metadata. Generated artifacts go to `build/`.
For a different installation path, use [project.config.local.json](docs/configuration.md#build-configuration).

For an installed, registry-backed Windhawk installation, run the following in
an **elevated PowerShell session**:

```powershell
.\install.ps1
# For an existing local installation:
.\update.ps1
```

Installation validates `settings.default.json`. An optional `-SettingsPath`
selects another settings file. Updating preserves existing settings and the
enabled/disabled state. An interrupted update leaves the mod disabled.
Portable Windhawk installations should use the editor workflow instead of
these installation scripts.

## Restore native selection

Disable the mod in Windhawk. Alternatively, from elevated PowerShell:

```powershell
.\disable.ps1
# Enable it again:
.\enable.ps1
```

If an old drawing artifact remains on the desktop, focus the desktop and press
F5. The mod does not change global system colors or the Windows accent color.

## Validation

The shared renderer passes 16 checks for alpha blending on light and dark
backgrounds, rounded corners, paint clipping, thin/empty rectangles, zero opacity
and different DPI scales. Manual validation confirmed desktop selection with
growth, shrinkage and mouse release without drawing trails. These checks do not
establish compatibility with every Windows build.
